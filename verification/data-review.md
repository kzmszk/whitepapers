# 独立データレビュー

確認日：2026-09-22。対象：`scripts/build_demo_data.py`、`prototype/app.js`、`prototype/index.html`。対象ファイルは変更していない。ブラウザ動作・実ダウンロードは親担当の検証範囲。

## 結論

2020–2025の比較画面で使用する年平均、指数化、前年比に算術誤りは見つからなかった。原本CPIから独立再計算し、JavaScriptの `model()` と `recipe()` をフォーム入力用の最小アダプタで実行した。指摘した欠測表現と保存条件は親担当が修正し、再検証で解決を確認した。今回の範囲に未解決の指摘はない。

## 指摘

1. **解決済み（元P2）：燃料輸入額の空文字。** 初回は1979–1987の未収録値9件が `value: ""` として配布され、UI範囲外の計算でNaNになることを再現した。修正後の生成処理はNoneと空文字を除外し、数値型を検証する。再生成された燃料系列は1988–2025の38件で、全系列の値が数値であることを確認した。1979–1980を指定した `model()` の再実行では値がnullになり、ゼロにもNaNにもならない。元々、現行UIの2020–2025の値への影響はなかった。
2. **解決済み（元P3）：保存条件の選択列定義。** `recipe()` の `series_definitions` に選択系列の `id`、`source_id`、`item_code`、`source_column`（ある系列のみ）、`unit`、`aggregation` が追加された。実関数の再実行で元データの定義との一致を確認した。鉱物性燃料はコード3・金額列33（0始まり）、エネルギーCPIは0167、総合CPIは0001を保持する。

## 原本から確認したこと

別のPython処理で、CP932の `raw/context/cpi-monthly-2020base.csv` を読み、列名と品目コードを照合してDecimalで平均を計算した。制作スクリプトを実行し直して結果を見るだけの確認にはしていない。

- 原本は80か月。2020–2025は各年1–12月が重複なく存在し、2026は1–8月のみ。
- 総合：列1／コード0001。エネルギー：列739／0167。持家の帰属家賃を除く総合：列735／0163（列番号は0始まり）。
- 完全年の3系列×6年＝18年次値は生成JSONと一致（許容誤差1e-10）。2026は3系列とも年平均データに存在しない。
- 2020年平均は総合100.00033333333333、エネルギー100.00016666666667、帰属家賃除外100.00058333333334。月次指数が小数第3位までのため、100との差は0.001未満。これをさらに開始年100へ指数化する処理は整合する。
- 原本CSVのSHA-256とJSONの出典ハッシュは一致。
- 初回確認で保存済み `processed/comparison-data.json` と `prototype/data.json` は一致し、`processed/comparison-observations.csv` もJSONの各観測と一致した。修正後も2つのJSONの一致と、全観測の数値型・燃料の38年範囲を再確認した。ファイル間一致だけでは欠測の正しさを証明しないため、空文字の除外を別に確認した。

## 実行したJavaScriptの確認

Nodeの `vm` で実ファイルを読み、末尾の `init()` 呼出しのみ外し、フォーム値・選択系列を供給して計算関数を実行した。ブラウザDOMやダウンロード成功を証明するテストではない。

- 2020–2025の指数比較：6年、3系列とも有限値。基準年は浮動小数の誤差を許容して100。
- 同期間の前年比：CPIは2019年未収録のため2020年値がnull。燃料輸入額は2019年があるため2020年値は-33.6066739077%。
- 2025年の前年比は上表と一致。
- 開始年2023への変更、2025年だけの選択、選択系列ゼロの各ケースを実行。
- 2023年基準の条件JSONは `base_year:2023`、正しい指数式、選択した2出典と64桁ハッシュを保持する。
- 修正後の短い再確認では、選択した3系列の条件定義が元データと一致し、現行期間の値が有限、2020年のCPI前年比がnullであることを再実行で確認した。

## 読解・出力仕様の確認

CSV生成処理は画面と同じ `model()` の値を使う。丸め前の計算値、表示用小数1桁、変換前の値と単位、出典URL、原本ハッシュ、取得時刻、変換方法、基準年を保存する。nullは空CSVセルとなり、0とは区別する。引用符のエスケープ、UTF-8 BOM、CRLFが実装されている。実ファイルの保存操作はこの担当では実行していない。

「鉱物性燃料の輸入額」は輸入価格指数ではなく、CPIは家計支出額そのものではない。画面は両者の違い、為替・数量・補助制度等、因果関係を判定できないことを説明している。2020年基準の取得版固定、2025年の貿易統計が確々報、独自再集計であり白書の図の完全再現ではないことも明記されている。これらはデータの使い方に対応した説明である。

エネルギー白書本文の政策説明の根拠確認、2026年版の有無、画像の権利条件、Cloudflareでの動作は、この追加レビューの範囲外。
